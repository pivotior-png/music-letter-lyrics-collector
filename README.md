# Music Letter Lyrics Collector

## Overview
Music Letter Lyrics Collector is a Python-based tool developed for an educational programming project.

The project aims to collect and organize song metadata and available lyrics information using public APIs, in accordance with their terms of use.

## Purpose
- Educational and non-commercial programming practice
- Song metadata management
- Lyrics data collection and validation
- Preparation for word-level lyric synchronization

## Technology
- Python
- LRCLIB API
- lrc.red API
- Other permitted public lyrics APIs

## Project Status
Under development (v0.1).

## Data and Copyright
This repository does not distribute copyrighted audio files or full song lyrics.

All third-party API usage is subject to the respective provider's terms and licensing requirements.
